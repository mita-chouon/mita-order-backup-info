Mita Order Backup は、三田調温工業の受注管理データを定期的にバックアップし、会社のGoogle Driveへ保存するための社内専用ツールです。

一般のお客様向けのサービスではありません。
このサイトはアプリとデータの取り扱いを説明する案内ページです。業務システムへのログインやバックアップファイルの閲覧・ダウンロードはできません。

現在は自動バックアップの初期構築・試験段階です。定期実行は、動作確認の完了後に開始します。

バックアップの用途

受注管理システムのデータ保全と、障害時の復旧に備えるために使用します。会社が許可したGoogleアカウントの非公開フォルダを保存先とします。

利用できる方

三田調温工業が承認した管理者が、自社のバックアップ業務に利用します。一般向けの新規登録やサービス提供は行いません。

日報バックアップへの適用（2026年11月25日追記）

この案内とプライバシーポリシー・利用条件は、三田調温工業の日報・残業時間集計システム用の社内専用ツール Mita Daily Backup にも適用します。

日報のバックアップ対象は public スキーマ内の日報・勤務時間等の業務データです。Supabase Auth を含むシステム全体のバックアップ・復旧は対象外です。受注管理とはDB接続情報、認証情報、Google Driveの保存フォルダを分離します。

日報の自動バックアップは構築・検証中で、取得と隔離環境での復元検証に成功してから日次実行を有効にします。日報の世代削除は無効とし、既存の手動バックアップも削除しません。受注管理の既存運用は変更しません。
