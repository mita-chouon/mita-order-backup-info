プライバシーポリシー

最終更新：2026年11月12日

1. 利用目的とGoogle Driveへのアクセス

三田調温工業は、Mita Order Backup を自社の受注管理データの保全・復旧のために使用します。Google Driveへのアクセスは、バックアップの保存、保存情報の確認、再取得による整合性確認、および承認された保存世代の整理を目的とします。

使用する権限は drive.file です。本アプリが作成したファイル、または利用者が本アプリでの使用を許可したファイルを対象とします。

2. 取り扱うデータ

バックアップには、受注管理の業務情報、社員情報、更新履歴、および復旧に必要な認証データが含まれます。また、保存・照合のためにGoogle Drive上の対象ファイルの識別情報、サイズ、整合性確認用の情報を扱います。

この案内サイトには、ログイン、問い合わせフォーム、アクセス解析機能を設けていません。サイト配信に伴う情報の取り扱いは、配信事業者GitHubのプライバシーステートメントもご確認ください。

3. 保存先と管理方法

バックアップは、三田調温工業が管理するGoogleアカウントのマイドライブ内の非公開フォルダに保存し、アクセス権限を必要な範囲に制限します。Google Driveの標準の保護機能を利用し、独自のファイル暗号化は追加しない方針です。

自動処理はGitHub ActionsからGoogle Driveへ直接保存する構成です。認証情報は公開コードに含めず、アクセス制限された保管機能で管理します。バックアップ本体、認証情報、業務データを公開リポジトリや公開ページに掲載しません。

現在、自動処理は初期構築・試験段階です。運用開始後の保存方針は日次30世代・月次12世代を基本とし、世代整理は試験と承認を経て有効にします。保存・照合に失敗した処理では、既存バックアップの世代削除を行わない設計です。

4. 第三者への提供・技術支援

データの販売、広告利用、一般公開は行いません。バックアップ処理・保存のためにGitHubおよびGoogleのサービスを使用します。

Freely Productionなどの技術担当者による復元・技術支援時のデータ利用は、三田調温工業の個別の依頼と承諾に基づき、必要な範囲で行います。

本アプリによるGoogle APIから受け取った情報の利用・転送は、Limited Useの要件を含むGoogle API Services User Data Policyに従います。

5. アクセス許可の取り消しと保存データ

管理者はGoogleアカウントから本アプリへのアクセス許可を取り消せます。取り消すと以後の自動保存はできなくなりますが、保存済みのバックアップが自動で削除されるものではありません。保存データの削除や運用終了は、復旧に必要なデータの保全を確認したうえで管理者が判断します。
